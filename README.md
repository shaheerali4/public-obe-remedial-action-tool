# OBE Remedial Action Tool

This public showcase illustrates how an Outcome-Based Education (OBE) tool tracks remedial reassessment for Course Learning Outcomes (CLOs). See [project links](project-links.md) for public availability.

## Sample student roster

Download [the synthetic CSV roster](examples/student-roster.csv) and open it in a spreadsheet editor. Each row represents one student and lists the CLOs they need to reassess. The first row of sample data lists two CLOs in a single cell. Keep that cell quoted when editing the CSV as plain text so its comma is preserved.

The names, course, and IDs are fictional. Use synthetic records when sharing examples in this public repository, and keep real student records and generated reports in approved private storage.

The sample is an input illustration. Running the workflow requires access to the private application.
